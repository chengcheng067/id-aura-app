## 关键踩坑
- Tailwind 的 `<alpha-value>` 必须直接出现在颜色值字符串里（不能裹在嵌套 css var），实测支持 `rgb(var(--x) / calc(var(--x-a, 1) * <alpha-value>))` 写法，bg-pine/20 正确编译为 `calc(... * 0.2)`
- 「Unexpected token '<'」pageerror 来自静态 SPA fallback：/env-config.js 不存在时 fallback 返回 HTML，Chrome 用 JS MIME 解析顶头 '<' 报错。修复：`tmp/theme-shots/shoot.mjs` 对 `/env-config.js` 等容器期脚本直接返回 404
- 看板截图必须从「项目详情页」回首页才有内容（建档成功后自动跳转 `/project/:id`）
